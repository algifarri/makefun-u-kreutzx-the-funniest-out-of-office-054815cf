Write one line of an out-of-office auto-reply, the funniest you can, in 140 characters or fewer. A judge model picks the line that lands hardest. Free to enter, $2 pot, top 10 paid.

## Run it

```sh
python3 main.py
```

The program writes one line (121 characters) to `/output/entry.txt`:

> I'm out of office until Monday. Urgent emails will be handled by my auto-reply, which is also out of office until Monday.
